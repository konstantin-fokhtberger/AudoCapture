# Changelog: итерация I3

## 2026-09-08
- Added: NativeM4AExporter, общая временная шкала capture, полный decode-check AAC, эксклюзивная публикация и Retry Saving.
- Changed: один M4A stereo 48 kHz/192 kbit/s вместо двух MP3; имя по локальной дате-времени старта, коллизии с `(2)`; временные PCM в `.sessions/<UUID>`, удаление только после подтверждённого сохранения. Повторная проверка готового файла перед cleanup после retry.
- Fixed: сохранение пауз/начальных смещений между источниками; перекрытия обрезаются. Нулевая дорожка не считается захваченным источником, пустые исходники не дают успешный файл тишины.
- Removed: ProcessMP3Encoder и зависимости от ffmpeg/lame. Optional MP3-поля оставлены только для чтения исторических metadata.
- Documentation: ADR-005, implementation I3, актуальные README и бэклог. B06-B07 done; B14 in_progress до длительного live-теста в B11.
- Validation: 46 тестов/10 suites, 0 failures, 5.484 s; сборка app и smoke, `Smoke checks passed.`. Реальная запись, гарнитура и матрица OS ещё не проверены.
