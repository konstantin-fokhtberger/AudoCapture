# Текущие ограничения AudoCapture

Дата: 2026-09-08. Этот документ отражает реализацию I1-I4/B10; апрельский constraints сохранён как исторический.

- Build target: arm64/macOS 14.0; runtime macOS 14/15/26 и другой M-series Mac ещё не проверены.
- Swift 6.1+ и полный Xcode нужны для сборки. Конечный recorder использует только системные frameworks и Swift runtime.
- Выход: один AAC/M4A, stereo 48 kHz/192 kbit/s; промежуточные PCM16 mono + stereo. Экспорт без ffmpeg/lame.
- Нужны Microphone и Screen Recording permissions; их изменение может требовать перезапуска приложения.
- System audio зависит от ScreenCaptureKit и доступного дисплея. Изменение оборудования консервативно останавливает запись; бесшовный reconnect не реализован.
- Сон инициирует async Stop. Завершение до закрытия крышки/принудительного сна не гарантируется; работа может завершиться после wake. Нет crash/power-loss recovery.
- Retry последнего экспорта доступен в текущем процессе; при ошибке исходники сохраняются. Публикация использует hard links в локальной папке с поддержкой этой операции.
- Timestamps/длительность валидируются в пределах 24 h. Длительные 30 min/2 h записи, drift, RAM/CPU и реальные устройства ещё не прошли pilot.
- Нет AEC/автонормализации/транскрибации. При использовании динамиков возможен акустический дубль системного звука в микрофоне.
- Локальные bundle подписаны ad-hoc. Developer ID/notarization/распространение и Gatekeeper на другом Mac не проверены.
