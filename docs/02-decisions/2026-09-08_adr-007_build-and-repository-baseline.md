# ADR-007: сборка arm64/macOS 14 и исходный репозиторий

## Status
accepted, 2026-09-08. Реализация B10 и явное поручение пользователя создать новый закрытый GitHub-репозиторий.

## Context
Локальный Git не содержал коммитов и remote. Debug/release перезаписывали один bundle, deployment target оставался 13 при целевой матрице 14/15/26. Часть тестов создавала рабочие логи и использовала порог быстродействия вместо проверки порядка запуска.

## Decision
- Минимальная macOS 14, только arm64. Матрица macOS 14/15/26 требует отдельных runtime-испытаний; build target не является заявлением совместимости.
- `Config/Info.plist` хранит bundle metadata, версию 0.1.0/build 1 и LSMinimumSystemVersion 14.0. Package.swift задаёт macOS 14; сборщик проверяет совпадение минимальной версии Mach-O и plist.
- Debug/release сохраняются раздельно в `.build/bundles/<configuration>/AudoCaptureApp.app`. Подготовка bundle в уникальной staging-папке, проверка plist/arm64/minOS/ad-hoc signature до замены результата данной конфигурации.
- Сборщик использует полный Xcode из стандартного расположения, если DEVELOPER_DIR не задан. Собранное приложение не зависит от Homebrew/сторонних encoder-бинарников.
- Ad-hoc signature предназначена для локальной проверки. Developer ID, hardened runtime, notarization и испытание скачанного файла остаются B12/B13.
- `.gitignore` исключает build/IDE state, .env, логи и аудио; из `.codex` версионируется только Run action. Создать baseline и отправить исходники в закрытый `konstantin-fokhtberger/AudoCapture` по явному запросу пользователя. Публикация Release и загрузка аудио не входят в этот шаг.
- Тесты используют disabled logger либо собственную временную папку и удаляют созданные файлы. Проверка параллельного Start использует барьер: оба источника входят до разрешения завершить startup. Timeout служит пределом ожидания, не критерием быстродействия.
- Core Audio stream configuration выделяет необходимое количество байт с корректным alignment, а не `size` экземпляров AudioBufferList. Форматтер логов переиспользуется actor, FileHandle закрывается через defer.

## Alternatives considered
| Вариант | Компромисс |
|---|---|
| Universal binary | Добавляет неподтверждённую платформу Intel вопреки scope |
| Оставить deployment 13 | Лишний контракт поддержки; целевой первый выпуск начинается с 14 |
| Генерировать настройки из дополнительной системы конфигурации | Избыточно для двух простых файлов; достаточно проверки plist против Mach-O |
| Подключить CI до pilot | Пока не требуется; локальный сборщик и тесты достаточны для первого baseline |

## Consequences
- Две конфигурации не затирают друг друга; build-проверки выявляют рассогласование OS/архитектуры.
- Закрытый GitHub содержит исходники и исторические проектные документы. Непроверенная аппаратная совместимость явно остаётся открытой.
- Размер bundle измеряется отдельно от RAM/CPU. Малый бинарник не доказывает лёгкость во время длительной записи.
