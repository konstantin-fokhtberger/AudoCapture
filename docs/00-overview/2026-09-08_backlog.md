# Бэклог AudoCapture: простой рабочий выпуск

- Дата: 2026-09-08.
- Основание: пользователь поручил зафиксировать задачи и начать итерационную реализацию, отдавая приоритет простоте и быстрому использованию.
- Это текущий рабочий бэклог. Он сокращает объём первого выпуска по сравнению с полным планом аудита, не отменяя выявленные риски.
- Статусы: `todo`, `in_progress`, `done`, `deferred`. Done означает выполнение указанного критерия, а не готовность всего приложения.
- Правило: одна ограниченная итерация -> проверка -> краткий результат -> следующая итерация. Без нового backend, DI container, DB, сервера, виртуального драйвера или двух реализаций захвата для разных OS.

## Цель первого выпуска

Открыть приложение, нажать Record, затем Stop, получить один автоматически сохранённый локальный M4A. Существующие ScreenCaptureKit + AVAudioEngine, нативный UI, Apple Silicon. Целевая матрица macOS 14/15/26; заявлять поддержку только после проверки.

Подтверждено пользователем: итоговый файл должен быть один - M4A/AAC с именем по локальной дате и времени старта, например `08-09-2026 10-04.m4a`, содержащий микрофон и весь системный звук. Раздельные дорожки - только промежуточные файлы; они остаются резервом при ошибке экспорта. После проверки общего файла промежуточные файлы удаляются. Сведение и необходимое выравнивание входят в первый выпуск; сложная адаптивная коррекция drift не вводится без измеренной необходимости.

Для первого выпуска при смене устройства/формата или сне допустимо явно остановить запись и безопасно сохранить доступное. Бесшовное продолжение не требуется. При недоступности источника остаётся существующий честный single-track fallback с заметным предупреждением. Незаметная потеря дорожки недопустима.

## Результат итерации I1

B01 выполнена: между порциями converter получает `.noDataNow`, а не `.endOfStream`. Добавлены реальные regression tests: 20 mono-буферов на каждой из 16/44.1/48/96 kHz и stereo-последовательность с противоположными сигналами в каналах. До исправления тесты воспроизвели дефект (157 assertions); после - 22 теста в 6 suites прошли. Завершение и drain converter остаются B03; реальная запись ещё не проверена. Следующая после I1 итерация B02-B05 завершена; см. результат I2 ниже.

## Результат итерации I2

B02-B05 реализованы и проверены: guards manager, уникальные папки, reset writer, drain/close, ожидание Quit, ошибки source -> UI, partial/unknown metadata и отмена permissions. 38 тестов в 9 suites и smoke check прошли. Статус done здесь означает код и автоматические проверки; реальные privacy dialogs, аудиоустройства и compatibility остаются B09/B11-B13. См. [отчёт I2](../05-implementation/2026-09-08_iteration-02-safe-recording.md).

## Результат итерации I3

B06-B07 реализованы: нативный AAC/M4A, единый датированный файл, проверка декодированием, эксклюзивная публикация, сохранение исходников при ошибке и Retry Saving. Внешний MP3 exporter удалён. B14 реализована и проверена синтетически; остаётся in_progress до длительной реальной записи B11. Закрытие кода I3 не означает аппаратную приёмку приложения.

Автоматические проверки: 46 тестов в 10 suites и smoke check прошли; см. [итоговый отчёт I3](../05-implementation/2026-09-08_iteration-03-single-m4a.md). Реализация I4 завершена, см. ниже.

## Результат итерации I4

B08 выполнена: компактный UI, одна Start/Stop-кнопка, timer, active tracks, refresh при activation/wake, Finder. B09 реализована в коде (HAL/OS/engine notifications, cancellation/Stop, причина interruption в metadata), но остаётся in_progress до физических испытаний USB/Bluetooth, дисплеев и сна. 52 теста в 11 suites прошли; debug bundle запущен, idle-окно проверено визуально без аудиозаписи. См. [отчёт I4](../05-implementation/2026-09-08_iteration-04-ui-and-interruptions.md).

Run action и тонкий build/run wrapper уже добавлены как часть удобного запуска B10; прочие критерии B10 остаются открытыми. Следующая итерация: B10, затем контролируемая живая проверка B09/B11/B14. Завершение экспорта до принудительного сна не гарантируется.

Реализованы ignore, arm64/macOS 14, отдельные debug/release bundle, test logger/cleanup, startup barrier и исправление аллокации AudioBufferList. 54 теста в 12 suites прошли, оба bundle собраны и проверены. ## Неизвестные зависимости

- Доступность Developer ID/Apple Developer Program и Mac коллег с целевыми OS. Выяснить перед B12, не блокирует I1-I5.
- Целевой сервис транскрибации и его лимиты. Для первого выпуска не добавлять сервис, аккаунты или API; проверить импорт, когда сервис выбран.
- Согласие на live recording и privacy prompts определяется текущим явным запросом/контекстом перед испытанием; не записывать посторонние разговоры в фоне.
