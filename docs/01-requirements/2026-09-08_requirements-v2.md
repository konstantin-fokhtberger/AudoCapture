# Требования v2: простой рабочий выпуск

## Metadata
- Date: 2026-09-08
- Version: 2.0
- Status: draft
- Пользовательские цели подтверждены; техническое разбиение первого выпуска - рабочий план реализации, не отдельное подтверждение каждого предложения.

## Objective
Локальная запись всего доступного системного аудио Mac и микрофона по кнопке, с автоматическим сохранением для последующей транскрибации. Быстрый запуск, небольшой объём приложения, минимум действий и зависимостей. Apple Silicon, macOS последних двух-трёх лет, распространение коллегам вне App Store.

## Scope
- Существующие SwiftUI, ScreenCaptureKit и AVAudioEngine.
- Рабочая целевая матрица: macOS 14/15/26; подтверждение поддерживаемых OS по испытаниям.
- Подтверждённый результат: один M4A (AAC) с датой-временем старта в имени, содержащий микрофон и весь системный звук, без внешнего encoder. Раздельные дорожки допустимы только как промежуточные файлы. Нативный экспорт - изменение относительно v1.1, внедряемое в итерации I3.
- Обычный Start/Stop/Quit и безопасное сохранение обязательны. Runtime failures явно отображаются.
- Single-track fallback сохраняется согласно ADR-003, с ясным состоянием неполноты.
- При отключении устройства/сне допустима безопасная остановка; автоматическое восстановление отложено; простое сведение и временное выравнивание обязательны.

## Functional Requirements
- Имя файла: `dd-MM-yyyy HH-mm.m4a`, например `08-09-2026 10-04.m4a`; в UI `08-09-2026 10:04`. Использовать локальные дату/часовой пояс на старте capture после permissions, сохранять их до завершения. Время Stop/экспорта не меняет имя. Коллизия имени получает `(2)`, `(3)` и т.д.; без перезаписи.
- Уникальная папка сессии; перезапись другой сессии запрещена.
- Потоковая конвертация не теряет все порции после первой; завершение converter учитывает хвост.
- Один lifecycle manager независимо от UI; второй Start/Start во время Stop не допускается.
- Сохранение без Homebrew/ffmpeg/lame после I3; при неудачном экспорте исходная запись остаётся.
- Интерфейс показывает, какие источники активны, время и результат сохранения; ошибки имеют понятный следующий шаг.

## Non-Functional Requirements
- Без backend, DB, драйвера, второго capture backend, встроенной транскрибации.
- Нагрузка/память измеряются перед pilot; неограниченный рост очередей/логов недопустим.
- Сборка воспроизводима, release arm64; Developer ID/notarization для передачи коллегам.

## Acceptance Criteria
- Критерии и статусы задач ведутся в [рабочем бэклоге](../00-overview/2026-09-08_backlog.md).
- Unit-тесты проверяют реальные контракты и негативные ветки; живое аудио проверяется отдельно.
- До подтверждения B11-B13 приложение не считается готовым к распространению.

## Open Questions
- Целевой транскрибатор и его ограничения на длительность/размер единого файла.
- Наличие Developer ID и целевых Mac для compatibility tests.
- Промежуточные WAV удаляются после верифицированного успешного экспорта; при ошибке остаются для retry.

## История и приоритет
v1.1 и старые ADR не переписаны. Текущая инструкция пользователя о простоте имеет приоритет над объёмом предложений предыдущего аудита. Изменение формата/минимальной OS будет отражено в отдельном ADR при реализации; I1 не меняет эти решения.
